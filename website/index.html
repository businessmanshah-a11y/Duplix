Core Capabilities

Engineered Specifically for macOS

No slow virtual machines, no complex terminal hacks, and zero recurring subscription fees.

⚡️

Instant APFS Copy-on-Write

Duplicates gigabyte-sized app bundles in milliseconds using macOS kernel-level pointer referencing. Consumes 0 additional bytes on your SSD until files mutate.

🔒

Full Session & Data Isolation

Each clone runs with its own sandboxed Application Support, preferences, cookies, cache, and token stores. Sign into work, personal, and client accounts side-by-side.

🎨

CoreGraphics Retina Badging

Renders crisp, vector badges in all 10 standard macOS icon resolutions (16px to 1024px) with drop shadows and contrast borders for instant identification in Dock and Spotlight.

🖥

Native SwiftUI Dashboard

Features an intuitive application scanner, batch clone generator (up to 5 copies in 1 click), live badge editor, and one-click session cache resets.

🧠

Multi-Engine Intelligence

Automatically detects Electron, Chromium (Chrome, Brave, Arc, Edge), Gecko (Firefox), and Native Cocoa/AppKit binaries to pass the exact sandboxing flags required.

🛡

Apple Silicon Ad-hoc Signing

Automates recursive quarantine stripping (xattr -cr) and ad-hoc code signing (codesign -s -) so clones launch instantly without Gatekeeper warnings.
